# Phase 3 Customer Dashboard UI

The customer experience was redesigned based on the supplied Agri Farmer Adviser dashboard concept.

### Customer UI changes
- Removed technical metrics such as Vector DB, Embeddings and Knowledge Mode.
- Added Tamil Nadu / India agriculture visual branding.
- Added farmer-field sidebar imagery.
- Added hero banner with Tamil Nadu landscape, mountain, temple and farmland.
- Added Quick Questions panel.
- Added agriculture topic cards.
- Added simplified customer-facing source display.
- Added feedback buttons.
- Kept technical controls in the Developer tab.
- Preserved the existing RAG/OCR/FAISS backend.
